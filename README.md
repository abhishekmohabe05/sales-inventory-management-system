# Sales & Inventory Management System

## 📌 Project Overview
The Sales & Inventory Management System is a web-based application developed to manage products, inventory, sales transactions, and reports efficiently. The system helps small businesses reduce manual work and improve accuracy in stock management.

---

## 🚀 Features
- Secure User Login
- Dashboard Overview
- Product Management
- Add/Edit/Delete Products
- Sales Management
- Automatic Stock Update
- Low Stock Alerts
- Reports Generation
- Responsive UI Design

---

## 🛠 Technologies Used
- Python Flask
- MySQL
- HTML
- CSS
- JavaScript
- Jinja2 Templates

---

```bash
app/

```

---

## ▶️ How to Run the Project

1. Clone the repository
2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Run the Flask application

```bash
python run.py
```

4. Open browser and visit:

```bash
http://127.0.0.1:5000
```
